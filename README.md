# Guia de Causas — Rede FiBrasil

Consulta rápida e pesquisável do catálogo de causas usado para o fechamento de TTKs na operação de NOC, organizada por categoria (rede física, equipamentos, configuração, energia, fatores externos, terceiros/tenant, operacional, cliente/acesso e administrativo).

## O que é

Página única (HTML/CSS/JS, sem dependências externas) que lista as causas de fechamento de chamado, com busca por palavra-chave e filtro por categoria. Ao clicar em uma causa, abre a definição completa usada pela equipe para padronizar o fechamento.

## Como usar

Abra o arquivo [`index.html`](./index.html) no navegador, ou publique via GitHub Pages para acesso direto por link.

## Tecnologias

- HTML, CSS e JavaScript puro (sem frameworks ou build).
